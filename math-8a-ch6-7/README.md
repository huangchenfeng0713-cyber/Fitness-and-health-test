# 数据与证明 · 互动课堂

北师大版（2024）数学八年级上册 **第六章 数据的分析**、**第七章 命题与证明** 的教师授课课件。
一个 `index.html` 就是全部：双击即可在浏览器中打开，断网也能用，不依赖任何外部字体、脚本或图片。

共 70 页，按教科书的节、课时编排，每页都有可以拖动、点击或逐步呈现的互动内容。

## 上课怎么用

| 操作 | 按键 / 按钮 |
|---|---|
| 下一步、下一页 | `→`、`空格`、`PageDown`（翻页笔可直接使用） |
| 上一步、上一页 | `←`、`PageUp` |
| 第一页 / 最后一页 | `Home` / `End` |
| 目录 | `T`，或左上角菜单按钮 |
| 画笔批注 | `P`，每页的笔迹分别保存，可撤销、清除、用荧光笔 |
| 全屏 | `F` |
| 计时器、字号、深浅色主题 | 右上角工具栏 |

- 带“步骤 1/5”的页面会逐条呈现：结论、证明的每一行、图形的变化都跟着按键一步步出来。
- 图中带光晕的圆点可以拖动；读数、关系式会实时更新。
- 证明页可以勾选“理由挖空”，把括号里的依据遮住，让学生口答后再点开。
- 地址栏会记住当前页（如 `index.html#s722-corr`），刷新后停在原处；封面上的“从第六章开始”“从第七章开始”可直接跳转。

## 内容一览

**第六章 数据的分析**

- 6.1 平均数与方差（4 课时）：众数与算术平均数，“移多补少”，极端值的影响；加权平均数（面积模型、跷跷板支点）；离差平方和、方差与标准差（正方形面积模型）；方差的应用（选拔、分组）
- 6.2 中位数与箱线图（2 课时）：中位数、百分位数（14 岁身高百分位数表）；四分位数、箱线图的画法与解读
- 6.3 哪个团队收益大：用平均数、方差、四分位数与箱线图综合分析；综合与实践“哪个城市夏天更热”
- 回顾：知识结构图，12 道综合练习

**第七章 命题与证明**

- 7.1 认识证明（3 课时）：视觉错觉、“铁丝比赤道长 1 m”、归纳的反例（*n*² − *n* + 11）；定义与命题、条件与结论、真假命题与反例；基本事实、定理与证明，对顶角相等，《原本》
- 7.2 平行线的证明（2 课时）：三类角，基本事实“同位角相等，两直线平行”，判定定理的证明；性质定理的证明（含“两直线平行，同位角相等”的反证法动画，教科书中为选学），平行于同一条直线的两条直线平行，判定与性质的对比，潜望镜，平行线间的“拐角”
- 回顾：可点击的“证明之树”（点一个定理，高亮它的全部依据），回顾与思考，12 道综合练习

例题和练习的数据大多为本课件自编，并已逐一核算（见 `tests/`）。教科书中的部分经典问题按原样保留，便于与课本对照，如篮球队员的身高、14 岁学生身高百分位数值表（教科书据世界卫生组织数据制作）、铁丝与赤道、*n*² − *n* + 11、蜂房。定义、定理、基本事实的表述与教科书一致。

## 修改与构建

源文件在 `src/` 下，按课时分文件：

```
src/index.html            页面骨架
src/styles/               base（配色、布局）、components（通用组件）、slides（各页样式）
src/js/core.js            工具函数：SVG、拖动、补间动画、统计与几何计算、课程结构
src/js/charts.js          坐标轴、条形图、箱线图、扇形图
src/js/widgets.js         读数面板、滑块、测验、证明书写、分类游戏、翻转卡
src/js/geom.js            角的标记、“两条直线被第三条直线所截”图形
src/js/slides/*.js        每个课时一个文件，按教学顺序排列
src/js/app.js             翻页、步骤、目录、画笔、计时、快捷键
```

修改后运行（需要 Node.js 18 及以上，无其他依赖）：

```bash
node build.mjs                      # 把样式和脚本内联，生成单文件 index.html
node --test tests/stats.test.mjs    # 核对例题中的统计数值
```

新增一页：在对应课时的文件里调用 `M.slide({ id, sec, lesson, kind, title, layout, html, mount })`，
`html` 中给元素加 `data-step="n"` 即可逐步呈现；`mount` 返回的 `onStep(n)` 可让图形随步骤变化。
