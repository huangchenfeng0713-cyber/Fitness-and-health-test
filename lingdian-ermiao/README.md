## 旁白文稿


**一、尺度**

这是地球。我们所有人的家。
从四百公里高的空间站望下去，它很大，很蓝，也很安静。
可如果，再飞远一点——
一九九零年，旅行者一号在离家六十亿公里的地方，回头望了一眼。
地球，只剩下一个不到一像素的光点。
银河系里，有数千亿颗恒星。而在可观测的宇宙中，像银河系这样的星系，还有数千亿个。
在这样的尺度里，我们连一粒尘埃都算不上。

**二、时间**

宇宙已经存在了一百三十八亿年。
如果把这一百三十八亿年，压缩成一年——
一月一日零点，宇宙诞生。
九月初，地球才刚刚形成。
十二月底，恐龙登场，又匆匆谢幕。
而人类，直到十二月三十一日，午夜前的最后十来分钟，才终于出现。
有文字记载的全部历史，只占最后十来秒。
而你的一生，按八十年算——不到零点二秒。

**三、被遗忘的人**

地球上，曾经活过大约一千一百七十亿人。
他们也曾为明天辗转难眠——为一场考试，一笔债，一段感情，别人的一句闲话。
如今，那些烦恼，连同他们的名字，都被时间轻轻抹去了。
我们的烦恼，也一样。
一百年后，不会有人记得，你今天为什么焦虑。

**四、转折**

听起来，这像是一个悲伤的结论。
但换个角度想一想：
既然宇宙并不在意我们，我们也就不必背负整个宇宙的期待。
既然一切终将被遗忘，那此刻的尴尬、失败，和别人的目光，也就没有那么重要了。
渺小，不是一种悲哀。渺小，是一种自由。

**五、去活**

人的一生，大约只有四千个星期。
所以，去看一次日出吧。不为拍照，只为看着它升起来。
去好好吃一顿饭。慢一点，尝出它的味道。
去和老朋友喝一杯，聊到忘了时间。
去见想见的人，把一直没说出口的话，说出来。
去抱一抱你的父母，趁他们还在身边。
去走没走过的路，去淋一场雨，去海里游一次泳。
去爱，哪怕会受伤。去试，哪怕会失败。
跳舞的时候，别管自己跳得好不好看。

（纯音乐蒙太奇，约 36 秒）

你身体里的碳、氧和铁，都诞生于远古恒星的熔炉与爆炸。
宇宙花了一百三十八亿年，用尘埃和星光，才拼出了一个会哭、会笑、会仰望星空的你。
这零点二秒，是宇宙借给你的。

**六、尾声**

我们微不足道。
也正因如此——
每一秒，都值得尽情地活。

## 数据出处

- 宇宙年龄约 138 亿年；地球约 45.4 亿年；恐龙约 2.33 亿年前出现、6600 万年前灭绝；智人约 30 万年；文字约 5200 年。按「压缩成一年」换算：智人 12 月 31 日 23:48，文字 23:59:48，80 年人生 ≈ 0.18 秒。
- 旅行者一号 1990 年 2 月 14 日在约 60 亿公里外拍摄「暗淡蓝点」，地球不足一个像素。
- 银河系约 1000–4000 亿颗恒星；可观测宇宙星系数量估计为数千亿量级。
- 历史上出生过的人口约 1170 亿：美国人口咨询局（PRB）估算。
- 80 年 ≈ 4174 周（旁白取「大约四千个星期」）。

## 制作方式

整部片子用 Python + ffmpeg 按脚本化的时间线剪辑，可以完整重新渲染：

- `build.py`：时间线（每句旁白配哪些镜头、停顿多长、用什么转场）、镜头渲染、音频混合、字幕和最终合成。
- `graphics.py`：代码逐帧生成的画面，包括宇宙日历动画、“四千个星期”方格、照片缓推镜头。
- 转场全部是叠化：段落之间 0.8–1.5 秒，段落内 0.6 秒，蒙太奇 0.35 秒，叠化中点对齐配乐节拍（`src/music/598_beats.npy`）。
- 旁白处音乐自动压低约 11 dB，整体响度 -16 LUFS。
- `vo/`：旁白文本（`lines.tsv`）和生成好的配音。如需重新配音，用 `tools/tts.py`。

### 重新渲染

```bash
pip install numpy pillow edge-tts   # 另需系统里装好 ffmpeg（带 libass）
python3 tools/fetch_sources.py      # 下载素材，约 5 GB
python3 build.py --preview          # 960×540 快速预览 → out/preview.mp4
python3 build.py                    # 1080p 成片 → out/零点二秒.mp4
```

原始素材不放进仓库：Mixkit 的许可不允许把素材单独再分发，NASA 的 4K 原片单个约 2 GB。`fetch_sources.py` 会按 `build.py` 里用到的编号重新下载。
