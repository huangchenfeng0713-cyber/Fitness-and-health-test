# 圣显 · Claude 版

一部 4 分 14 秒的知识性短片：以“圣显”（hierophany，神圣借世俗之物显现自身）为唯一主线，
讲中国人的祭祀经验。全片无旁白，画面、文字与配乐 *Sacred Geometry* 逐小节对齐，
全部画面由本目录的 Python 代码逐帧生成（skia 矢量绘制 + numpy/OpenCV 合成），没有使用任何图片或视频素材。

## 叙事主线

以《寻找哲人石：伊利亚德的思想之钥研究》（杨洁，中国社会科学出版社）的研究结论为骨架：

| 书中观点 | 在片中的落点 |
| --- | --- |
| 神圣总是借世俗之物显现；物仍是物，却已不只是物（“圣显辩证法”，p.300–301） | 贯穿全片的复句：“石头仍是石头”“龟甲仍是龟甲”“木牌仍是木牌”“碗筷……留给不在场的人” |
| “圣显”的三种理解：显圣物 → 显现的事件 → 意识的参与（第三章） | 结构：石、树、坛（物）→ 灼龟、点主、清明除夕中元（事件）→ 阳台上的一炷香、“吾不与祭，如不祭”（人的参与） |
| “天国的乡愁”：渴望回到人神共处的太初（前言 p.7 注②） | 建木“众帝所自上下”→ 绝地天通 → “人心里，从此有了一种乡愁” |
| 世界之轴：圣显在世俗中确立绝对定点（前言 p.7 注④） | 建木、圜丘天心石、阳台的窗：“坛的中心，就是天地的中心” |
| 圣显的原型可被反复模仿，后人借象征化的效仿与神圣共情（p.261） | 冬至祭天、清明、除夕、七月半——每年重演 |
| 现代的圣显更个体化、境遇化，隐蔽于日常（p.249–250、p.264） | 城市越来越亮，阳台上为远方亲人点的一炷香 |
| 宗教人与圣显互生互构；圣显是“双向的门”：神圣向人显现，人也让神圣显现（p.247、p.301、p.38 注） | “吾不与祭，如不祭。——神圣借物显现，也借人显现。” |
| “神圣从未远离了人们，只不过是人们很少察觉”（结语 p.301） | 结尾：“石头仍是石头，烟仍是烟，神圣，从未远离。” |

片中刻意不出现“伊利亚德认为……”之类的导读口吻：书的观点只作为叙事的骨架，叙事的肉身是中国人自己的祭祀经验。

## 知识点与出处

- 建木：“建木在都广，众帝所自上下，日中无景，呼而无响，盖天地之中也。”（《淮南子·地形训》）；树形参照三星堆青铜神树（三层九枝、九鸟）。
- 绝地天通：“乃命重、黎，绝地天通，罔有降格。”（《尚书·吕刑》；又见《国语·楚语下》）
- 卜：商人在龟甲背面钻凿，以火灼之，正面现出裂纹（兆）以定吉凶；“卜，灼剥龟也……一曰象龟兆之从横也。”（《说文解字》）
- 圜丘（北京天坛，明嘉靖九年 1530 始建，清乾隆十四年 1749 扩建）：三层圆台，上层中心为天心石，外环九块扇面石，逐环加九，上层第九环八十一块，三层共二十七环；栏板 72/108/180 共 360；四出陛，每层九级；外方内圆两重壝墙。
- “冬日至，于地上之圜丘奏之，若乐六变，则天神皆降。”（《周礼·春官·大司乐》）
- 燔柴：“燔柴于泰坛，祭天也。”（《礼记·祭法》）；“其香始升，上帝居歆。”（《诗经·大雅·生民》）
- “万物本乎天，人本乎祖。”（《礼记·郊特牲》）
- 点主：旧时丧礼，神主牌上先写“神王”，由点主者以朱笔在“王”上加点成“主”，牌位自此为先人依附之所。
- “祭之日，入室，僾然必有见乎其位。”（《礼记·祭义》，未直接上屏，作为“木牌成为先人居所”的依据）
- “祭如在，祭神如神在。子曰：吾不与祭，如不祭。”（《论语·八佾》）
- 清明扫墓、插柳；碑文“音容宛在”；除夕为先人多摆一副碗筷；七月半（中元）放河灯，是夜月圆。

## 运行

```bash
pip install librosa skia-python opencv-python-headless numpy
# 字体（OFL）：思源宋体 Noto Serif CJK SC、霞鹜文楷 LXGW WenKai、Cormorant Garamond，放到 fonts/
python3 audio_analysis.py song.wav data/audio_features.npz
SX_AUDIO=song.m4a python3 render.py video --fps 30 --workers 4
python3 render.py sheet 0 254 64      # 全片缩略图检查
```

`film/core.py` 网格、音频包络、噪声、字体与后期；`film/elements.py` 各种程序化图形；
`film/scenes.py` 九个乐章；`film/script.py` 全部字幕；`film/text.py` 排版。
