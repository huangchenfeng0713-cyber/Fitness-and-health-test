# 人生不过几个八拍

一部约 89 秒的纯代码喜剧动画短片。一个胶囊小人从婴儿跳到老年，舞蹈风格随人生阶段一路变质：蹬腿、拍手、广播体操、正步、机械舞、摇花手、太空步、转脖子、八段锦、广场舞、太极……最后在走马灯里每拍闪一种风格，骤停，老人数到“七”，然后变回婴儿，喊出“八！”。

画面、音乐、口令、音效全部由本目录的 Python 代码生成。没有图片素材、没有录音素材、没有现成旋律。唯一的外部资源是 Edge TTS 合成的口令单字，已缓存在 `assets/tts/`。

## 交付物

| 文件 | 说明 |
|---|---|
| `deliverables/preview_480p.mp4` | 480p 全片预览（H.264 + AAC） |
| `deliverables/keyframes.png` | 关键帧总览：每个转场前后各一帧，加几个笑点帧 |
| `out/life_in_eight_beats_1080p.mp4` | 1080p 正式版，**在本机运行 `python render.py final` 生成**（见下） |
| 源码 | `render.py`、`lieb/`（画面）、`lieb/audio/`（声音） |

按要求，1080p 正式版放在本地电脑上渲染。云端这边只渲染了 480p 预览和关键帧图用于自检，并用 1080p 单帧测过管线（每帧 12–54 ms）。

## 在本机重新渲染

需要 Python 3.9+、ffmpeg（在 PATH 里），以及 `pip install -r requirements.txt`。

```bash
# macOS
brew install cairo pkg-config ffmpeg
pip install -r requirements.txt

# Windows（PowerShell）
winget install ffmpeg          # 或 choco install ffmpeg
pip install -r requirements.txt   # pycairo 有 Windows 预编译轮子

# Ubuntu / Debian
sudo apt install libcairo2-dev pkg-config ffmpeg fonts-wqy-zenhei
pip install -r requirements.txt
```

```bash
cd life-in-eight-beats
python render.py check      # 校验：时间轴、口令、关键帧、脚底打滑、口令起音对拍
python render.py audio      # 只生成 out/audio.wav（约 30 秒）
python render.py preview    # 480p 预览 -> out/preview_480p.mp4（4 核约 1 分钟）
python render.py final      # 1080p CRF 18 H.264 + AAC 192k -> out/life_in_eight_beats_1080p.mp4
python render.py sheet      # 关键帧总览 -> out/keyframes.png
python render.py still 25.1 60.9 --scale 0.5     # 任意时刻单帧
python render.py grid 40 43 12 g.png             # 某时间段的缩略图网格
```

- `final` / `preview` 按 CPU 核数自动并行（`--workers N` 可改），分段渲染、可中断续渲（已完成的分段带 `.done` 标记）。改了代码要重渲时，先删掉 `out/seg/`。
- 弹簧次级运动会预先模拟一遍并缓存到 `out/cache/`，缓存按源码哈希命名，改代码后会自动失效。
- 中文字体自动挑选：macOS 用 PingFang SC，Windows 用 Microsoft YaHei，Linux 用 Noto Sans CJK 或文泉驿。也可以用环境变量 `LIEB_FONT="字体名"` 指定。
- 重新获取 TTS（一般不需要）：`python -c "from lieb.audio.voice import fetch_all; fetch_all(force=True)"`。

## 单一事实来源：`lieb/timeline.py`

`TL = Timeline()` 是唯一的时间来源。

- 每段的每一拍都是一个绝对时间，统一用 `seg.t(beat)` 取（支持小数拍）。
- 口令、换装“噗”、哨子、咔咔、啪、嘿哈、咳嗽、风声、走马灯、骤停、静默，全部登记为 `TL.cues`。
- 关键帧（`lieb/choreo.py`）只写 `(段, 拍)`。和声音绑定的动作（比如四下“咔”）直接从 cue 里读拍号。
- 音乐的每个音符、鼓点、口令起音、音效都从同一批拍点和 cue 取时间。
- 镜头推拉、背景切换、拟声字、换装时间也全部来自 timeline。

`python render.py check` 的结果（全部 PASS）：

- 各段 BPM、八拍数和简报一致，S8 的快放半个八拍正好是 2 倍速。
- 每拍一个口令，字序正确（一二三四五六七八 / 二二三四… / 三二三四…），全部落在整拍上。
- 主角 181 个关键帧：107 个落在整拍，63 个落在半拍或 1/4 拍，其余在具名 cue 上（定格、咳嗽、骤停、七的结束、变身、八）。**没有游离帧。**
- 学生方阵 26 个关键帧全部在整拍。
- 16 次换装“噗”全部在强拍上（走马灯是每拍一次）。
- 每拍身体下沉的最低点和拍点误差 0.0 ms。
- 着地的脚（脚踩地、非太空步、非转圈）逐帧滑移 0 帧。
- 同一个动作原样连续重复最多 2 次。
- 144 个口令字的起音（5 ms 包络首次到达峰值 20% 的位置）和拍点误差最大 0.0 ms。这项检查和放置用的是同一个起音定义，验证的是放置、截断、混音这一路没有引入偏移。另外在合成好的 mp4 里实测鼓点起音对拍点：中位误差 −0.3 ms。

## 角色与动画系统

- **骨骼**（`lieb/skeleton.py`）：骨盆、胸、颈、头、双肩、肘、腕、髋、膝、踝。姿势 = 根节点（位置、骨盆偏移、身体旋转）+ 关节角度，手臂、脊柱、头用正向运动学计算。
- **双腿两骨 IK**：着地的脚，目标点存在世界或地面坐标里，所以骨盆怎么动脚都不会滑。目标够不着时自动降低骨盆（弯膝），不让脚悬空。抬脚换位时自动加抬腿弧线。
- **比例参数化**：头半径、颈、躯干长和宽、上下臂、大小腿、四肢粗细、驼背、肚腩、脚长，按阶段给预设：婴儿约 1:3，成人约 1:6，中年发福，老年驼背、屈膝、白发。在换装前后约一拍内连续插值，走马灯里每拍快速闪变。
- **渲染**（`lieb/draw.py`）：圆头粗线段加深色描边，圆脑袋、两点眼、眉毛、嘴，眉毛是主要表情。小人始终一本正经：眉头微压、嘴平，只在被哨子吓到时眉毛弹起，转晕时眼睛变蚊香圈。
- **服装**：连体衣 → 小红花 → 红领巾校服 → 迷彩（带帽）→ 卫衣耳机 → 衬衫领带工牌 → 广场舞红衣加红扇子 → 白色太极服（盘扣）。每次换装都在强拍上，配一圈“噗”烟雾。
- **次级运动**（`lieb/secondary.py`）：240 Hz 弹簧阻尼模拟，覆盖红领巾两条尾巴、领带、工牌挂绳、卫衣抽绳、扇子（腕部柔性铰接，跟随手腕角加速度和侧向加速度）、白发（两侧加头顶一缕）、山羊胡、肚腩（跟随骨盆竖直加速度）。白鹤亮翅定格时有阵风，白发随风飘。
- **动画原则**（`lieb/anim.py`）：
  - 先蓄力再出手：各风格的过渡曲线开头都有反向回拉。
  - 到位略冲过头再回弹：到达关键帧后叠加一个按动作幅度缩放的阻尼振荡，振荡从到达那一刻开始，所以“到位”正好在拍点上。
  - 重心先动：骨盆、身体这些根通道比四肢提前 1/8 拍取样，四肢正好在拍点到位。
  - 每拍全身下沉一次：最低点精确在拍点，1、5 拍更深；深度取最近一拍的风格，风格交叉渐变时下沉曲线也保持对称。
  - 风格切换：叠加参数（下沉深度、噪声、左右不同步、抖动、摆胯）在半拍内带缓动交叉渐变；关键帧值本身是连续的，不会跳变。
- **每种风格一种插值曲线**：

| 风格 | 曲线 / 质感 |
|---|---|
| 婴儿 | 大回拉加大过冲，带种子的平滑噪声（7°），左右手不同步 0.13 拍 |
| 幼儿园（傻动作） | 同类但较轻，噪声 3.5°，不同步 0.08 拍 |
| 广播体操 | 到位后定住约 30% 拍长，然后强 ease-out 快速方正地动过去，正好在下一拍落定 |
| 军训 | 78% 时间不动，最后一下猛切，近似阶梯 |
| 机械舞 | 16 分音符阶梯，最后一级落在拍点上，到位瞬间 23 Hz 微抖 |
| 街舞 | 正弦，摆幅大，持续摆胯，下沉圆滑 |
| 打工人 | 缓入沉重（smoothstep^1.7），到位后往回塌一点，有气无力 |
| 广场舞 | 小回拉后大幅弹性过冲，下沉尖锐 |
| 太极 | 非均匀 Catmull-Rom 连续圆弧，正弦缓动，重心左右移 |
| 快放武打 | 短促回拉，指数冲出，强回弹 |

- **群演**（`lieb/crowd.py`）：学生方阵 21 人、广场舞阿姨 6 人，复用同一套骨骼和渲染器，缩小、错位，各带 ±0.035 拍的时间偏移。阿姨走进走出用程序化步态（支撑脚在世界坐标里固定），不打滑。

## 转场（动作双关）

| 转场 | 做法 |
|---|---|
| S1→S2 | 婴儿站起后踉跄、风车一样挥舞的双臂越挥越往里收，在下一段的强拍上正好合成一下拍手 |
| S2→S3 | 转晕摇晃，哨声“哔！”，半拍后立正，接着是广播体操预备姿势；音乐被哨子掐断，只剩一串军鼓“预备—” |
| S3→S4 | 原地踏步 → 齐步 → 正步（全员向右转成侧面），下一段强拍“立定”，红领巾一“噗”变迷彩 |
| S4→S5 | 正步的僵硬直接变成机械舞：转回正面是一格一格“咔哒”转过来的，每个卡点都有伺服机械音和合成器重音，卡在 16 分音符网格上，不会像播放卡了 |
| S5→S6 | 太空步之后摇花手越摇越慢，同时音乐做磁带减速停下；键盘、桌子从画面右边滑入，椅子从左边滑到身下，手正好落在键盘上 |
| S6→S7 | 八段锦“两手托天”托到顶的那一拍，“啪！”手里弹出两把红扇子，桌子被“噗”走 |
| S7→S8 | 广场舞转圈越转越慢，转停时手臂顺势画圆，变成云手；阿姨们停下、摇头、散场 |
| S8→S9 | 白鹤亮翅定格：一根古筝轮指长音，加风声和飘起的白发，然后进入走马灯 |
| S9→S10 | 走马灯末尾的上升噪声在最高处被一刀切断，所有声音骤停 0.6 秒 |

## 音频（`lieb/audio/`）

- **全部用 numpy/scipy 程序化合成**：八音盒、玩具钢琴、钢琴、铜管、电子琴 lead、方波和锯齿贝斯、Rhodes、拨弦（向量化 Karplus-Strong，带按音推弦）、Pad、底鼓、军鼓、拍手、镲、木鱼、通鼓、锣。
- **配乐**：
  - S1 八音盒摇篮曲
  - S2 玩具钢琴；转圈时上行音阶，转晕时音高下垂跑调
  - S3 进行曲：钢琴“嘭恰”加铜管
  - S4 蝉鸣、低音嗡声、懒散军鼓 → 哨声后大鼓、铜管、军鼓滚奏
  - S5 电子：四拍底鼓、拍手、锯齿贝斯、机械卡点和弦；太空步时低通压下去，最后磁带减速
  - S6 慢速 lo-fi：七和弦、摇摆节奏、黑胶噼啪
  - S7 广场舞“动次打次”加五声音阶 lead
  - S8 古筝式拨弦（五声音阶），长音垫底；快放段把慢速版本 2 倍速播放（自然升八度）
  - S9 每拍拼贴上述各段的动机，叠一条上升噪声
  - S10 几乎为零：极轻的 pad 和泛音
  - 片名：S1 的开头四个音放慢，停在导音上不解决
- **旋律全部原创**，没有使用第九套广播体操或任何现成歌曲的旋律。
- **口令**：Edge TTS（`edge-tts`）逐字合成并缓存。各段声线：

| 声线 | 处理 |
|---|---|
| 婴儿 | 晓夏（童声）升调 +3 半音 |
| 幼儿园 | 晓夏童声 |
| 广播 | 云扬：喇叭带通 + 软削波 + 回声 + 体育场长混响 |
| 教官 | 云健：失真加短混响，用“一！二！”的吼法 |
| DJ | 云希：3/16 拍乒乓回声加混响 |
| 打工人 | 云希放慢、降调、低通 |
| 广场舞阿姨 | 辽宁晓北：廉价音箱带通加硬削波 |
| 老爷爷 | 云希降调、拉长、颤音 |
| 快放段 | 老爷爷声线 2 倍速，变成花栗鼠音 |
| 结尾 | 老爷爷声线拉得更长 |

  每个字的起音精确放在拍点上。没有 TTS 时会退化成共振峰“哔”声占位，时间点不变，方便后期替换（见 `lieb/audio/voice.py`）。
- **音效**：哨子（豌豆哨颤音）、咔咔（骨节脆响）、噗（换装）、伺服机械音、搓碟、风声、嘿哈（TTS）、咳嗽（噪声加喉部共振峰，加一点浊音）、打鼾、跺脚、啪（折扇）、键盘、椅子滚轮、小鸟、星星叮。
- **定格和停顿都被声音框住**：
  - S2 哨声后音乐断，只剩军鼓预备
  - S8 磁带骤停，空拍里只有咳嗽
  - 白鹤亮翅有长音加风声
  - S9→S10 全静音
  - 七之后约 1.5 秒真静音（混音时对音乐、音效、人声三轨都做了门限）

## 主要判断（自主决定，记录在此）

1. **没有可复用的分支**。仓库里没有 `next-beat-v2`、`mv-haifeng`。唯一的动画分支 `claude/shengxian-narrative-video-*` 是 skia 渲染、用外部歌曲、不合成声音，所以只借鉴了它“分段并行渲染 + ffmpeg 管道 + 可续渲”的结构。其余按简报用 pycairo + numpy/scipy + ffmpeg 重写。
2. **总时长约 88.8 秒，不是整 85 秒**。各段 BPM 和八拍数严格按表，S1–S9 合计约 76 秒。结尾需要的骤停、慢数到七、约 1.5 秒静默、八、片名一共约 12.5 秒。我没有为凑 85 秒去改 BPM 或砍八拍数，而是把片名卡压到 3 秒。
3. **S8 快放的结构**。理解为“2 个八拍里，第二个八拍的前半拍组（4 拍）用 2 倍速”：口令“二二三四”是花栗鼠声，然后磁带骤停，插入一个慢拍的空白让老人咳嗽，再接慢速“五六七八”。这样口令始终完整，咳嗽也被静默框住。动作顺序上，转圈先变成云手，阿姨散场后再“重新起势”，然后快放，然后白鹤亮翅。
4. **S10 数拍**。“五……六……七……”理解为完整的一到七，节拍不变（66 BPM），靠拉长字音体现“……”。“八”不在拍点网格上，放在约 1.5 秒静默之后，这是唯一一个刻意不卡拍的口令。
5. **S3→S4**。为了同时满足“原地踏步 → 齐步 → 正步”的转场和 S4“站军姿瞌睡 → 哨声 → 正步”的顺序：S3 最后两拍就开始正步，S4 第一拍“立定”换迷彩，正步在哨声后再出现一次（第二次更硬，不算原样重复）。
6. **教官“一二一”**。按“每个八拍都有一二三四五六七八”的硬性要求，S4 仍然数一到八，“一二一”体现在教官短促吼叫的念法上，没有替换口令字。
7. **S5 动作顺序**。简报是机械舞 → 摇花手 → 太空步，但转场要求从摇花手落到键盘上。所以实际是：机械舞 → 摇花手 → 太空步 → 再摇一次越来越慢的花手。两次摇花手速度和意图都不同。
8. **前景和背景的透视**。简报只给了中景、固定机位。为了让“只有主角慢半拍且顺拐”一眼可见，学生方阵放在后景并缩小；主角在前景的大小和方阵差别明显，这是刻意的。
9. **转身和转圈**。2D 平面骨骼没有真正的转身，转圈用“沿竖轴压扁 cos(角度) + 五官滑过 + 背面盖头发”来表现，转完整圈数时不会反向回转（代码里做了 360° 归一）。
10. **婴儿躺姿**。脸单独旋转（`facerot`）朝向观众，否则侧躺时两只眼睛会上下排列，读不出来。
11. **烟雾样式**。最初的“噗”是一团实心云，会把转场动作整个盖住半秒，和“笑点在变的瞬间”矛盾。改成向外炸开的环形烟圈，中心只闪约 70 ms。
12. **口令截断**。口令字最长截到 0.9 拍，避免和下一拍口令叠在一起。叹气“唉”和咿呀这类补充人声在下一个口令前截断。
13. **配音风格**。广播体操用“喇叭加体育场”的声线，只是音色，没有模仿任何原版录音。
14. **渲染位置**。按你的要求，1080p 正式版改到本地渲染：这边产出预览和关键帧图，README 写好本机命令。TTS 已缓存进仓库，本机渲染完全不需要联网。
