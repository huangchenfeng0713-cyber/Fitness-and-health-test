# 珍藏 · 悬浮单件展览

保留照片还原的毛绒挂件和晴空塔冰箱贴，在深黑环境中逐件悬浮展示。展示台为两张真实模型预览卡片，没有实体柜体或台座。柔和矩形主光、补光、轮廓光与环境反射共同照明。

## 结构

`src/app.js` 管理展览灯光、单件取景、手机手势、展示台和下载；`src/exhibit_objects.js` 将原照片模型接入悬浮展示。毛绒使用原始不对称薄填充几何、3072 图集和短绒，局部压痕上限 0.45 mm，阻尼复原，无持续重力。`src/magnet_scene.js` 的 `exhibition` 模式保留封口、纸卡、吸塑壳、本体的正常拆包动画与受限弯曲，暂停桌面刚体步进；空包装自动隐藏。

原 `plush_engine.js` 仍用于构造珠链和吊牌的初始姿态；柜体及旧桌面模块留作历史实现，不进入当前展览。所有模型单位为米。

## 构建

安装 Node.js、Python、Pillow；运行 `npm ci`、`pip install Pillow`、`python tools/build.py`。生成 `dist/keepsake.html`，离线图片无损内嵌，含全部运行资产。

开发时运行 `python tools/devserver.py 8877`，访问 `http://127.0.0.1:8877/index.html`。

## 验证

另起 `python dev/qa-server.py` 保存结果。浏览器打开 `dev/exhibit-check.html` 检查手机触摸与拆包，`?desktop` 检查桌面，`?offline` 与 `?offline&desktop` 在拒绝 HTTP/HTTPS 请求的 srcdoc 中加载最终 HTML。测试包含轻点与拖动区分、双指接续、取消与失焦、微小压痕复原、无自发抖动、五步拆包、弯曲复原、装回、三个手机横竖尺寸和触控区。

`dev/exhibit-check.html?desktop&export` 检查当前下载导出；`dev/exhibit-readback.html` 重新加载导出的 GLB。`python tools/validate_glb.py 文件.glb` 检查几何和内嵌图片。

`npm test` 另外检查基础模型几何、布标与原引擎行为。旧 `dev/check.html`、`offline-check.html` 是桌面场景的历史测试，不能用于当前展览验收。

`python tools/package_exhibition.py` 核验最终离线报告及源文件哈希后更新本地收藏包；保留已经交付的四份独立 GLB。源码包和仓库不含原始照片、身份证影像或云盘私人链接。

模型重建需本机另存的参考照片；已有模型与贴图可独立构建。尺寸及材料反应均为照片推定，不属于精密扫描。手机检查使用浏览器模拟事件，未逐台实测硬件。
