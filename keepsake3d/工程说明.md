# 珍藏 · 悬浮单件展览

保留照片还原的毛绒挂件和晴空塔冰箱贴，在深黑环境中逐件悬浮展示。展示台为两张真实模型预览卡片，没有实体柜体或台座。柔和矩形主光、补光、轮廓光与环境反射共同照明。

## 结构

`src/app.js` 管理展览灯光、单件取景、手机手势、展示台和下载；`src/exhibit_objects.js` 将原照片模型接入悬浮展示。毛绒使用原始不对称薄填充几何、3072 图集和短绒，局部压痕上限 0.45 mm，阻尼复原。珠链和吊牌的重力、碰撞、约束与休眠由 `plush_engine.js` 的 `exhibition` 模式处理，采用固定顶端悬挂和 480 Hz 子步进；当前模式不运行逐顶点晶格形变。`src/magnet_scene.js` 的 `exhibition` 模式保留封口、纸卡、吸塑壳、本体的正常拆包动画与受限弯曲，暂停桌面刚体步进；空包装自动隐藏。

`src/exhibit_motion.js` 管理按秒计算的角速度和指数惯性衰减，支持不同帧率一致的松手手感；静止时不循环摇摆。吊牌翻转轴穿过孔洞和质心，翻面时短暂提起，之后恢复自由悬挂。运动期间按动态边界居中并更新取景距离；直接抓取时保留手指对物体的控制。向外取景不滞后，向内平滑恢复。

`magnet_spec.json` 保存了 15 对正反面轮廓像素地标及背面单应矩阵。背面 UV 使用该矩阵映射到未改动的原始照片；正面仍使用原照片坐标。两个误连的轮廓凹口已恢复，图片加载失败会中止载入并提示重试。`dev/verify-magnet-textures.js` 验证贴图、法线、UV 连续性和凹口几何。

原 `plush_engine.js` 同时保留历史桌面模式；柜体及旧桌面模块留作历史实现，不进入当前展览。所有模型单位为米。

## 构建

安装 Node.js、Python、Pillow；运行 `npm ci`、`pip install Pillow`、`python tools/build.py`。生成 `dist/keepsake.html`，离线图片用无损 WebP 内嵌，含全部运行资产。`python tools/verify_embedded_assets.py` 对照编码字节、解码像素或 JSON 数据；图片的编码文件哈希不应直接与 PNG 源文件哈希比较。

开发时运行 `python tools/devserver.py 8877`，访问 `http://127.0.0.1:8877/index.html`。

## 验证

另起 `python dev/qa-server.py` 保存结果。浏览器打开 `dev/exhibit-check.html` 检查手机触摸与拆包，`?desktop` 检查桌面，`?offline` 与 `?offline&desktop` 在拒绝 HTTP/HTTPS 请求的 srcdoc 中加载最终 HTML。测试另包含 320/390/430 竖屏下自动翻牌逐帧边界、至少 85% 模型比例和回落后取景恢复。测试包含轻点与拖动区分、双指接续、取消与失焦、微小压痕复原、无自发抖动、五步拆包、弯曲复原、装回、三个手机横竖尺寸和触控区。

`dev/exhibit-check.html?desktop&export` 检查当前下载导出；`dev/exhibit-readback.html` 重新加载导出的 GLB。`python tools/validate_glb.py 文件.glb` 检查几何和内嵌图片。

`npm test` 的 78 项检查包含基础模型几何、布标、原引擎回归与新机制在 30/60/120 帧下的表现。安装 Python Playwright 并提供 `/usr/bin/chromium` 后，运行 `python dev/native-touch.py` 可复现原生触摸输入检查。旧 `dev/check.html`、`offline-check.html` 是桌面场景的历史测试，不能用于当前展览验收。

`python tools/package_exhibition.py` 核验最终离线报告及源文件哈希后更新本地收藏包；独立磁贴 GLB 须同步当前 UV 修复。源码包和仓库不含原始照片、身份证影像或云盘私人链接。

模型重建需本机另存的参考照片；已有模型与贴图可独立构建。尺寸及材料反应均为照片推定，不属于精密扫描。手机检查使用浏览器模拟事件，未逐台实测硬件。
